    Téléviseurs Samsung et LG

    Les rangées s'affichent partout où le client charge l'interface web du serveur : navigateur, application de bureau, mobile, Android TV.

    Les applications Tizen (Samsung) et webOS (LG) font exception : elles embarquent leur propre copie de l'interface web dans le paquet installé sur le téléviseur, et ne chargent donc jamais le index.html du serveur — celui que le plugin complète. Aucun réglage ne peut changer cela côté serveur.

    Pour les y faire apparaître, il faut reconstruire le paquet du téléviseur à partir d'une interface web où cette balise a été ajoutée avant </body> :

    <script plugin="MediaCarousel" defer="defer" src="/MediaCarousel/media-carousel.js"></script>

    Le rendu lui-même est prévu pour ces téléviseurs : espacements, contour de focus à la télécommande et tailles d'affiche adaptées à un écran regardé de loin.
