Top du serveur

Classement calculé à partir des statistiques de lecture de tous les comptes du serveur. Les épisodes sont comptabilisés au profit de leur série.

0 pour un palmarès historique. 30 pour un classement « tendance du mois ».
Plafonne l'influence d'un utilisateur qui revoit sans cesse le même titre. 0 pour ne pas plafonner.
Plus la valeur est élevée, plus le classement est précis et plus le calcul est long.

Top mondial

Classement récupéré auprès d'une base de données externe, puis rapproché de votre bibliothèque par identifiant TMDB ou IMDb.

TMDB : clé v3 ou jeton d'accès v4. Trakt : identifiant client (Client ID).
Code BCP-47, par exemple fr-FR.

Affichage sur la page d'accueil

Les classements apparaissent en rangées façon Netflix, juste sous tes bibliothèques. Rien à installer : le plugin s'intègre tout seul à l'interface web.

Prend effet au redémarrage du serveur. Pense à vider le cache de ton navigateur la première fois (Ctrl+Maj+R).

Rafraîchissement

La modification prend effet après redémarrage du serveur, ou via Tableau de bord → Tâches planifiées.
Utile pour les clients qui n'exécutent pas le script (Kodi, certains boîtiers TV).
